# Unit Economics Measurement Plan

Public pricing remains provisional until measured.

## Meter
Per tenant and, where relevant, per module:
- active users/seats
- agent runs
- model input/output tokens or equivalent model cost units
- vector/storage consumption
- file/object storage
- external API calls
- workflow executions
- notification/message sends
- support effort
- infrastructure allocation

## Compute
For each plan/module:
- direct model/API cost
- infrastructure cost
- support cost
- payment/billing cost
- gross margin
- implementation payback period
- performance-fee contribution where applicable

## Rule
No public plan or discount may be treated as final until expected gross margin and abuse/overage behavior are validated in UAT or pilot usage.
