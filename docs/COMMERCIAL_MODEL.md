# AIG CLOUD Commercial Model

## Approved baseline
AIG CLOUD uses a hybrid commercial model:

1. Platform subscription
2. Vertical-module subscription fees
3. Usage-based overages
4. One-time implementation/integration fees
5. Enterprise/private-deployment fees
6. Optional performance fees tied to verified incremental value

## Performance-fee rule
Performance fees must not be calculated as a blanket percentage of a customer's total GOP.

For AIG HOSPITALITY and AIG BOS, eligible value may include:
- incremental GOP
- incremental room/F&B/ancillary revenue attributable to the system
- verified labor savings
- verified energy/water savings
- verified maintenance-cost reduction
- verified procurement savings

Performance fee = agreed share of independently verifiable incremental value above an agreed baseline.

## Baseline requirements
Every performance contract must define:
- measurement period
- baseline period
- exclusions and extraordinary items
- source systems
- calculation formula
- dispute process
- approval authority
- audit evidence

## Pricing governance
Exact percentages, price points, minimums, caps, and discounts remain commercial-approval items until:
- hosting/model/API cost is measured
- support load is measured
- vertical UAT is complete
- unit economics are validated

## Product applicability
- AIG WORK: subscription + usage
- AIG HOSPITALITY: subscription + usage + optional performance fee
- AIG TRAVEL: subscription + usage + transaction/integration options
- AIG FINANCE: subscription + usage
- AIG STUDIO: subscription + media/model usage
- AIG ACADEMY: subscription + seat/course usage
- AIG PROJECTS: subscription + project/seat usage
- AIG BOS: subscription + device/site usage + optional performance fee
- AIG COMMERCE: subscription + usage/transaction options
- AIG UTILITIES: subscription + site/device usage + optional performance fee

## Technical implications
Billing must support:
- tenant plans
- module entitlements
- usage meters
- price books
- invoices/credits
- contract-specific overrides
- performance-baseline records
- evidence-linked performance calculations
- approval workflow before performance-fee invoicing
